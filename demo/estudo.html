Funções do 2º grau

Uma função do 2º grau tem a forma f(x) = ax² + bx + c, com a ≠ 0. O gráfico é uma parábola: virada para cima quando a > 0 e para baixo quando a < 0.

As raízes são os valores de x em que a parábola cruza o eixo horizontal, e o vértice é o seu ponto mais baixo (ou mais alto).

f(x) = x² − 4x + 3

Exercícios

  1. Encontre as raízes de f(x).
  2. Qual é o vértice da parábola?
  3. Para quais valores de x temos f(x) < 0?
